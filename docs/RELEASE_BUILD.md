# Reproducible Archival Build

The archival editions are produced by `tools/build_archive.py` (Python 3 standard library plus `git`; Pillow only for the placeholder edition). The citation hub is generated by `tools/build_cite.py` and the result is committed.

```bash
git checkout <the release commit>            # clean tracked tree required
python3 tools/build_archive.py               # writes both ZIPs and release/SHA256SUMS
python3 tools/build_archive.py --edition full
python3 tools/build_archive.py --edition placeholders
python3 tools/build_archive.py --check       # rebuild to temp files and compare bytes with release/*.zip
python3 tools/build_archive.py --list --edition full      # included/excluded files with reasons
python3 tools/build_archive.py --extract DIR --edition full  # unpack a tree (used by the tests)
```

## Outputs
| File | Contents |
|---|---|
| `release/drosies-world-v1.0.0-archival-full.zip` | Offline edition **with** the original illustrations (web-sized copies) under the rights in `ASSET_LICENSES.md`; for use only after the contract-scope check |
| `release/drosies-world-v1.0.0-archival-placeholders.zip` | Same software, every illustration replaced by a neutral placeholder; no protected artwork except code-drawn characters |
| `release/SHA256SUMS` | SHA-256 of both ZIPs |
| inside each ZIP | `RELEASE_MANIFEST.txt` (SHA-256 of every file), `EXCLUDED_AND_REPLACED_FILES.txt`, `ARCHIVAL_EDITION.md` (first line states which edition) |

## What makes it deterministic
Sorted `git ls-files`; fixed timestamps (2026-11-24 00:00:00), permissions (0644), compression level; byte-for-byte copies except for the documented transformations; placeholders generated with fixed parameters. Compressed bytes depend on the zlib build; compare `RELEASE_MANIFEST.txt` across machines. The release commit is not recorded inside the ZIP (a file cannot contain the hash of the commit that includes it): record it in the Zenodo notes.

## Transformations applied to produce the archival edition
Each is applied with an exact-match count assertion (the build fails if the source drifts): removal of the feedback form, Turnstile, Supabase configuration, GoatCounter scripts and visitor-counter fetch, Leaflet/OSM map and adult-contact form, Google Fonts imports and preconnects, YouTube iframe; page-flip served from `vendor/`; portraits replaced by a silhouette; root-absolute and directory links made relative; a short banner on the home page. See `docs/ARCHIVAL_EDITION.md`.

## Finalising licences (after the author's approval only)
The script deliberately creates no `LICENSE` file. After approval: copy `licenses/MIT.PROPOSED.txt` to `LICENSE` without the proposal banner, set `license` in `.zenodo.json` and `CITATION.cff`, update `ASSET_LICENSES.md`, rebuild, re-run the tests, and re-verify checksums.
