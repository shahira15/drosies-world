# 2. Keyword-to-page mapping

No search-volume numbers are given because none were measured. "Competition" is a qualitative judgment: **High** = broad terms dominated by large publishers/encyclopedias; **Medium**; **Low/achievable** = specific, long-tail intent where a small specialist site can plausibly rank. Revisit with real Search Console query data after 4–8 weeks.

Rule: one primary page per search intent. Other pages link to the primary page with descriptive anchor text rather than competing.
