# 3. Content gap analysis and 20 content opportunities

## Hubs: evaluation
| Proposed hub | Verdict |
|---|---|
| Fruit Fly Biology | **Built** (`/fruit-fly-biology/`): clear gap, original explanatory content plus references. |
| Science Activities for Kids | **Already exists** (`/science-activities/`): improved internal linking only. |
| Interactive Science Games | **Not built.** The games are already grouped on `/science-activities/` and in the nav; a separate page would split intent and be thin. Revisit once there are 8+ games. |
| Teacher Resources | **Built** (`/teacher-resources/`): lesson library as crawlable HTML (previously only PDF downloads and homepage cards), grade-band guide, standards note. |
| How Scientists Work | **Deferred** on purpose: it overlaps the unfinished Lab Notebook Academy. Build it around that feature when it ships. |

## Main gaps
1. No standalone, text-first pages on single fruit fly topics (anatomy, why scientists use flies, Morgan's white-eyed fly).
2. Lesson content exists mainly as PDFs and cards: little crawlable text per lesson.
3. Storybook text is inside images.
4. No scientific-skills pages (scientific method, observation, notebooks, posters).
5. Grade-specific landing pages (K, 1, 2) do not exist.

## The five strongest opportunities (recommended order)
1. **#1 Why do scientists use fruit flies?** Most direct match to a core keyword group; the content already half-exists on three pages and should be consolidated into one authoritative page. The existing sections can then link to it.
2. **#4 Fruit fly life cycle worksheet (printable)**: converts the best-performing topic into a concrete download; Lesson 2 PDF exists as a starting point.
3. **#2 Fruit fly anatomy with labelled diagram**: top-3 fruit-fly keyword with no dedicated page; the Secret Fly Lab artwork can supply the diagram.
4. **#3 Scientific method for kids with a fruit fly experiment**: biggest topical gap versus the target audience (teachers search this constantly); reuse the Climbing Challenge and virtual lab.
5. **#5 K–2 fruit fly science activities**: captures grade-level teacher queries with little competition from specialist pages.
