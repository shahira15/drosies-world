Cite Drosie's World

Researchers, educators, students and institutions are welcome to use and cite these free resources. This page gives ready-to-copy citations in APA 7, MLA 9, Chicago, BibTeX and RIS for the platform and for each resource that is live on the site today, plus bibliography files you can import into Zotero, Mendeley or EndNote.

Created by Shahira Helal Arzoo, Department of Biological Sciences, Texas Tech University. The affiliation identifies the creator; it does not mean that Texas Tech University publishes, endorses, sponsors or owns Drosie's World.

What is published, what is archived, and what is still to come

Resources are labelled by what actually exists today, so you can cite them accurately.

Published web resources

Live on drosiesworld.com

Every resource cited on this page is freely available at the URL shown. Websites change: cite the year and URL, and add your own access date if your style requires one. These resources are self-published; they have not been independently peer reviewed.

Archived with a DOI

The storybook

Drosie, the Fruit Fly (Version 1.0) is archived on Zenodo: https://doi.org/10.5281/zenodo.23550876. This is the only DOI currently associated with Drosie's World. Jump to its citations.

Not yet available

Software archive and DOI

No software DOI is listed for the games, simulations or website code, and none is claimed here. The source code is public on GitHub, but a public repository is not a permanent archive. If a versioned software release is later deposited in an archive such as Zenodo, its DOI and citation will be listed in this section. Until then, cite the URLs below, or the website citation above.

Future scholarly publications

No journal article, preprint or conference paper about Drosie's World is listed on this page. If one is published, it will be added here with its own citation and DOI.
