AI-assisted development disclosure

Drosie's World was developed with the help of generative AI tools. The creator directs the scientific and educational content and is responsible for it. ChatGPT (OpenAI) assisted with project conceptualisation, brainstorming, educational content development, simulation specifications, scientific explanations, prompt development, code generation, troubleshooting and feature planning. Claude Code (Anthropic) assisted with repository-level implementation, interface development, code generation, debugging, testing, documentation and release preparation. Not all code or content was written by hand, and AI tools are not listed as authors. No student learning outcomes have been established for these resources; the software documents technical functionality only.
