# Statistical validation

Three different things are kept separate here. **Passing numerical benchmarks is not comprehensive scientific validation.**

## 1. Numerical benchmarking (done, automated)
`validation/make_reference.R` runs **R 4.3.3 + metafor 4.4.0 (metadat 1.2.0)** on documented datasets and writes `validation/reference/reference.json` (raw inputs + outputs + provenance). `tests/test_validation_r.py` recomputes everything in Python from the raw inputs and compares (default rtol 1e-7).
Datasets (all from `metadat`): `dat.bcg` (BCG trials; RR/OR/RD; moderators ablat/alloc/year), `dat.normand1999` (MD/SMD/ROM), `dat.molloy2014` (ZCOR), `dat.raudenbush1985` (SMD; moderator weeks), `dat.bangertdrowns2004`, `dat.hackshaw1998`, `dat.nielweise2007` (zero-event cells).
Covered: MD, Hedges g (incl. tiny n), lnRR/ROM, OR, RR, RD (with zero-cell correction), Fisher z, sampling variances, IV weights, common-effect, random-effects (REML, DL, PM), Hartung-Knapp variants, Cochran Q (+p), τ², tau-based I²/H², prediction intervals (metafor convention and Riley t_{k-2}), leave-one-out, subgroup analysis (per-group fits + common-τ² moderator test), meta-regression (single/multiple/categorical moderators; REML/DL/PM; z and knha tests; QM, QE, R²).
Edge cases (11 entries: 9 synthetic pooling sets, tiny-n SMD, missing rows): k=2, k=3, zero heterogeneity, identical effects, extreme heterogeneity, very unequal study sizes, extreme effect sizes, tiny variances, one dominant study, n=2-4 per group, zero-event studies, missing rows (explicit listwise deletion), invalid/zero/negative/infinite variances (rejected), non-estimable regressions (rejected), non-convergence (raises `ConvergenceError`), scale invariance.
**Result: all benchmarks pass.** 

### Defects this process found and fixed
1. `risk_difference` ignored its continuity correction (zero-event studies got variance 0). Fixed.
2. Hedges' J used the approximation `1-3/(4df-1)`; metafor uses the exact gamma form. Approximation is ~1% off at df=2. Exact form now used; approximation kept only for comparison.
3. SMD variance: two published large-sample formulas exist (Hedges & Olkin / metafor "LS" vs Borenstein J²·Var(d)); they differ up to ~8% at tiny n. Both now available (`vtype`), default LS, documented.
4. I² has two definitions: Q-based (Higgins & Thompson) and τ²-based (metafor print). My earlier tests never checked I². Both are now reported and labelled.
5. Prediction intervals: metafor uses z (or t_{k-1} with HKSJ); Riley et al. recommend t_{k-2}. Both implemented (`pi_method`), default Riley, documented.
6. HKSJ with identical effects crashed (division by zero). Now returns NaN + warning.
7. REML previously used a bounded optimiser with an absolute tolerance; replaced by scale-free root finding on the exact restricted-likelihood score (tested to machine precision).
8. The earlier "BCG reference values recalled from memory" test is superseded by values generated by R.

### Documented deviations / reference limitations
- All-identical effects with HKSJ: metafor returns p = 0 for an undefined statistic; we return NaN + warning (intentional).
- `tiny_variances` case: metafor's convergence threshold is absolute (1e-10), so its τ² stops short when τ² ~ 1e-8; our solution satisfies the REML score equation to 1e-17. Tolerance for this single case is 1e-3 (asserted in tests with the direction of error).
- metafor's PM uses `uniroot` with tolerance ~1e-4 by default; the reference is generated with `control$tol=1e-12`.
- Package `meta` (R) could NOT be installed here (CRAN's current version needs a newer R; archived tarball download failed). Cross-validation against `meta` is therefore **not done** (blocker documented).

## 2. Methodological correctness (partly done, human review pending)
Benchmarks show we compute what metafor computes; they do not show the method suits a dataset. Guarded in code: refuse <2 studies; warn k<5 for τ²/PI; refuse regression with residual df<2 or collinearity; warn <10 studies per moderator; refuse missing/invalid variances; explicit dropping of missing rows. Lessons state estimator-choice caveats (no estimator is universally optimal).
Not covered: dependence, rare-event/zero-event model-based methods (MH/Peto/GLMM/Bayesian), publication-bias methods, multilevel/RVE/network/DTA/dose-response (not implemented).

## 3. Independent expert review (NOT done)
No qualified statistician has reviewed the code or lessons. See `expert_review/` (package generator) for sharing.



## v0.3 addendum: advanced methods (benchmarked vs R/metafor 4.4.0)
Mantel-Haenszel OR/RR/RD and Peto OR (bcg, nielweise incl. zero cells), Egger regression and Begg rank tests (4 datasets), cumulative meta-analysis, Q-profile CI for tau2/I2, influence diagnostics (rstudent, Cook, hat, tau2.del), three-level REML (`rma.mv`, REML log-likelihood agrees to 1e-8) with cluster-robust CR1 variance, IRR, prevalence transforms (PR/PLO/PFT/PAS incl. zero and full counts), design effect (hand-checked).
Findings: (1) metafor computes the MH/Peto estimate and variance from UNCORRECTED tables; the 0.5 correction only affects per-study effects used for Q (my first version corrected the tables: wrong for zero-cell studies). (2) metafor's RD variance is the Sato et al. estimator, not Greenland-Robins. (3) Begg's p matches R's EXACT Kendall test when n<50 and no ties. (4) metafor's confint() uses uniroot with abs tolerance ~1.2e-4; our Q-profile root is closer to the exact solution (asserted in tests).
NOT implemented (stated in the UI): trim-and-fill, selection models, PET-PEESE, CR2/Satterthwaite robust variance, shared-control covariance matrices, GLMM/Bayesian/network/DTA/dose-response, trial sequential analysis.


## v0.4 addendum: advanced methods II (benchmarked vs R 4.3.3 / metafor 4.4.0 / clubSandwich 0.5.10 / ape 5.7.1 / base R)
Reference: `validation/make_reference_v04.R` -> `validation/reference/reference_v04.json`; tests `tests/test_advanced2_r.py`.
**The reference script was audited before benchmarking** (script success is not correctness). The audit found: (1) trim-and-fill reference silently errored (`control` passed twice) - fixed and every reference section now asserted non-error; (2) the first DTA table gave rho = -1 and tau2 ~ 0 (boundary solution: flat likelihood, a poor benchmark) - replaced by a synthetic table (simulated, seed 1) with an interior optimum, while a boundary table is kept as a *warning* test; (3) a name collision (`year` data vs result) corrupted the CR2 moderator reference - renamed; (4) the Bayesian `log_marginal` omits constants and is not benchmarked.
Defects found by the benchmark in my own code: CR2 first omitted the D_j factor in the adjustment matrix B_j (SE 0.049 vs clubSandwich 0.0845); the multivariate outcome order in the test followed the wrong factor order.
Model checks: Berkey 1998 reproduces the values published in the metafor documentation (beta = -0.339, 0.353); NMA league table is invariant to the choice of reference treatment (catches wrong multi-arm covariances); direct-only networks reduce to pairwise meta-analysis; PET/PEESE equal `lm` with 1/v weights; Bayesian results come from an independent R integrate()/uniroot implementation.
Tolerances: trim-and-fill final refit in metafor stops at its default Fisher-scoring tolerance (1e-5), so estimates agree to ~3e-4 relative; the imputed values themselves are identical.
Packages that could not be installed (CRAN needs newer R): **netmeta, mada, bayesmeta, dosresmeta, metasens, meta** - NMA/DTA/Bayesian are therefore benchmarked against `metafor::rma.mv` / independent integration, NOT against the field-standard packages; status `requires_external_validation` until run on a machine with those packages (`validation/external_workflows/`).
Not implemented, lesson + R workflow only: dose-response (dosresmeta), selection models, one-stage IPD GLMMs, rare-event GLMM, Guyot IPD reconstruction, node-splitting/design-by-treatment inconsistency tests.
